# 🛍️ Customer Shopping Behavior Analysis 

## 📌 Project Overview
This project analyzes customer shopping behavior using data from 3,900 purchases to understand purchasing patterns, product preferences, discounts, and customer loyalty.

The project uses Python for data cleaning and EDA, MySQL for SQL analysis, and Power BI for interactive data visualization.

## 🛠️ Tools & Technologies
- 🐍 **Python:** Data cleaning, EDA, and feature engineering
- 🐼 **Pandas & NumPy:** Data manipulation
- 🗄️ **MySQL:** SQL queries and business analysis
- 📊 **Power BI:** Interactive dashboard
- 📓 **Jupyter Notebook:** Python analysis
- analysis
- 🎨 **Gamma** – Project presentation


## 🔄 Project Workflow
1. **Data Cleaning:** Loaded the dataset, handled missing values, and prepared data using Python.
2. **Exploratory Data Analysis:** Explored customer demographics, purchase amounts, product categories, and shopping patterns.
3. **SQL Analysis:** Analyzed revenue, customer segments, discounts, product ratings, shipping preferences, and subscriptions using MySQL.
4. **Power BI Dashboard:** Created visualizations to highlight customer behavior and purchasing trends.

## 💡 Key Business Insights
- Understand customer purchasing patterns and preferences.
- Identify popular products and customer segments.
- Analyze discount usage and subscription behavior.
- Support customer loyalty and targeted marketing strategies.

## 📁 Project Files
- 📓 **Jupyter Notebook:** Python data cleaning and EDA
- 🗄️ **MySQL File:** SQL queries for business analysis
- 📊 **Power BI Dashboard:** Interactive customer shopping analysis

## 🚀 How to Use
1. Download or clone this repository.
2. Run the Jupyter Notebook to explore and clean the dataset.
3. Execute the SQL queries in MySQL Workbench.
4. Open the Power BI `.pbix` file in Power BI Desktop.
